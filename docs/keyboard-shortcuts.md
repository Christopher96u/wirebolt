# Keyboard shortcuts

[Documentation](README.md)

`⌘` = Command, `⇧` = Shift, `⌥` = Option, `⌃` = Control. Shortcuts apply to the focused workspace and may be disabled while an action is unavailable.

| Action | Shortcut |
| --- | --- |
| Open workspace | ⌘O |
| New tab | ⌘T |
| New HTTP request | ⇧⌘N |
| New folder | ⌥⌘N |
| Save request | ⌘S |
| Close tab | ⌘W |
| Send HTTP request | ⌘Return |
| Connect / disconnect WebSocket | ⌃⌘Return |
| Focus URL | ⌘L |
| Filter requests | ⇧⌘F |
| Add a field row | ⇧⌘K |
| Copy cURL | ⇧⌘C |
| Split right | ⇧⌘D |
| Next tab | ⌃Tab |
| Previous tab | ⇧⌃Tab |
| Select tab 1–9 | ⌘1–9 |
| Navigate back / forward | ⌃⌘← / ⌃⌘→ |
| Git collaboration | ⇧⌘G |

Within the environment editor, **⌘K** adds a variable entry. The app's menu bar shows shortcuts in the context where they apply. **⌘N** retains native New Window behavior; use **⇧⌘N** for a new HTTP request.
